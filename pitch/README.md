# Carpool Venture 313 pitch

This folder contains the final hackathon presentation materials for Carpool.

- `Carpool_Venture313_Official_Template.pptx` is the seven-slide deck built from the official Venture 313 template.
- `Carpool_Venture313_Video_Pitch.mp4` is the narrated 1080p pitch video. Runtime: 6 minutes 52 seconds.
- `app-home.png`, `app-riders.png`, and `app-trip-share.png` are live product captures used in the video.
- `source/render_pitch.swift` contains the local video renderer and narration script.
